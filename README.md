# 🔒 Vulnerability Manager

Система управления уязвимостями с распределенной архитектурой.

## 📁 Структура проекта

- `docs/` - Вся документация проекта
- `scripts/` - Скрипты развертывания и управления
- `services/` - Основной код приложения
- `templates/` - HTML шаблоны
- `models/` - Модели данных
- `config.py` - Конфигурация проекта

## 🚀 Быстрый старт

См. документацию в `docs/guides/QUICK_START.md`

## 📚 Документация

Вся документация находится в папке `docs/`:
- `docs/README.md` - Обзор документации
- `docs/INDEX.md` - Индекс всех документов

## 🔧 Развертывание

См. `docs/deployment/` для инструкций по развертыванию.

## 📞 Поддержка

Для вопросов и проблем см. документацию в `docs/`.
