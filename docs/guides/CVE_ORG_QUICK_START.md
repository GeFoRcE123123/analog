# 🚀 Быстрый старт: Автоматическое скачивание CVE с cve.org

## ⚡ Быстрая настройка (5 минут)

### 1. Первичная полная синхронизация (опционально, ~2-4 часа)

```bash
# На Backend VM или Parsers VM
ssh user@10.0.88.20  # или 10.0.88.23

cd ~/vulnerability_manager
python3 services/full_cve_sync.py
```

Это загрузит все ~380,000 CVE в вашу базу данных.

### 2. Настройка ежедневного автоматического обновления

```bash
# На той же VM
crontab -e

# Добавьте эту строку (запуск каждый день в 3:00 ночи):
0 3 * * * cd /home/user/vulnerability_manager && /usr/bin/python3 services/daily_cve_sync.py >> /var/log/cve_sync.log 2>&1

# Сохраните и закройте редактор
```

### 3. Проверка работы

```bash
# Проверка логов
tail -f /var/log/cve_sync.log

# Или проверка количества CVE в БД
ssh user@10.0.88.11
echo '123' | sudo -S docker exec vulnerability_db psql -U admin -d vuln_db -c "SELECT COUNT(*) FROM turn;"
```

## ✅ Готово!

Теперь у вас настроено:
- ✅ Ежедневное автоматическое обновление CVE данных
- ✅ ~380,000 CVE записей в базе данных
- ✅ Все данные в формате JSON 5.x

## 📋 Что происходит

1. **Ежедневно в 3:00** запускается скрипт `daily_cve_sync.py`
2. Скрипт обновляет репозиторий с GitHub (`git pull`)
3. Обрабатывает все новые/измененные CVE записи
4. Сохраняет их в базу данных
5. Логирует все операции в `/var/log/cve_sync.log`

## 🔧 Изменение времени запуска

Отредактируйте crontab:

```bash
crontab -e
```

Измените время в формате:
```
МИНУТА ЧАС * * * команда

Примеры:
0 2 * * *  # Каждый день в 2:00
0 4 * * *  # Каждый день в 4:00
0 */6 * * *  # Каждые 6 часов
```

## 📊 Мониторинг

```bash
# Последние записи лога
tail -n 100 /var/log/cve_sync.log

# Поиск ошибок
grep -i error /var/log/cve_sync.log

# Статистика синхронизации
grep "Синхронизация завершена" /var/log/cve_sync.log | tail -5
```

## ⚠️ Важно

- Убедитесь, что `git` установлен: `which git`
- Проверьте место на диске: `df -h` (нужно ~1-2 GB)
- Проверьте доступ к GitHub: `ping github.com`
