# 👤 Добавление второго разработчика в репозиторий

Инструкция для владельца репозитория: как дать второму разработчику права на запись.

---

## 🎯 Зачем это нужно?

Чтобы второй разработчик мог:
- ✅ Заливать изменения напрямую в main-new
- ✅ Видеть все изменения на GitHub
- ✅ Работать в одной ветке с вами

---

## 📋 Пошаговая инструкция

### Шаг 1: Откройте настройки репозитория

1. Перейдите на GitHub: `https://github.com/GeFoRcE123123/analog`
2. Нажмите вкладку **Settings** (вверху страницы)
3. В левом меню выберите **Collaborators** (или **Manage access**)

### Шаг 2: Добавьте второго разработчика

1. Нажмите кнопку **Add people** (или **Invite a collaborator**)
2. Введите:
   - **GitHub username** второго разработчика, или
   - **Email**, который он использует на GitHub
3. Нажмите на найденного пользователя

### Шаг 3: Выберите права доступа

Выберите роль: **Write** (права на запись)

**Роли:**
- **Read** - только чтение (не подходит)
- **Write** - чтение и запись (нужно для работы)
- **Admin** - полные права (обычно не нужно)

### Шаг 4: Отправьте приглашение

1. Нажмите **Add [username] to this repository**
2. GitHub отправит email-уведомление второму разработчику

### Шаг 5: Второй разработчик принимает приглашение

Второй разработчик должен:
1. Проверить email от GitHub
2. Перейти по ссылке в письме
3. Нажать **Accept invitation**

---

## ✅ Проверка

### Проверить, добавлен ли разработчик:

1. Перейдите в **Settings → Collaborators**
2. Вы должны увидеть второго разработчика в списке с ролью **Write**

### Второй разработчик может проверить:

```bash
# Попробовать клонировать репозиторий
git clone https://github.com/GeFoRcE123123/analog.git

# Попробовать сделать push (после коммита)
git push origin main-new
```

Если есть права - команды выполнятся успешно.

---

## 🔐 Альтернативный способ: Personal Access Token

Если не хотите добавлять как Collaborator, можно использовать Personal Access Token.

### Для второго разработчика:

1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Generate new token (classic)
3. Выберите права: `repo` (полный доступ к репозиториям)
4. Скопируйте токен
5. Используйте токен вместо пароля при push:

```bash
git push origin main-new
# Username: ваш_github_username
# Password: вставьте_токен_здесь
```

---

## ⚠️ Важные моменты

1. **Безопасность:** Давайте права только доверенным людям
2. **Мониторинг:** Регулярно проверяйте список Collaborators
3. **Удаление:** Можете удалить доступ в любой момент в Settings → Collaborators

---

## 🆘 Решение проблем

### Проблема: "Permission denied" при push

**Решение:**
1. Проверьте, принял ли второй разработчик приглашение
2. Проверьте, что роль установлена как **Write**
3. Попросите второго разработчика перелогиниться на GitHub

### Проблема: Не могу найти пользователя

**Решение:**
- Убедитесь, что введен правильный GitHub username
- Попросите второго разработчика проверить его username в профиле GitHub
