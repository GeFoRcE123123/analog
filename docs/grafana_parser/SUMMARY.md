## 📊 Совместимость с БДУ ФСТЭК

### ✅ Полностью поддерживается (100%)

**Основные поля:**
- `cve_id` - CVE идентификатор
- `title` - название уязвимости
- `description` - полное описание

**БДУ поля:**
- `vendor` - "Grafana Labs"
- `product_name` - название продукта
- `cvss_score` - оценка CVSS
- `severity` - уровень опасности
- `metrics.cvss_v3` - детальные метрики CVSS
- `published_date` - дата публикации
- `remediation_method` - "Обновление ПО"
- `remediation_info` - информация об устранении
- `references` - ссылки на источники
- `vendor_comments` - благодарности

**Итого:** 10 полей из 10 основных

---

### ⚠️ Частично поддерживается

- `affected_versions` - из Fixed Versions (требует инверсии)
- `software_type` - определяется автоматически
- `remediation_date` - используется published_date
- `exploitation_method` - извлекается из Summary
- `last_modified_date` - из Updated Date (если указана)

**Итого:** 5 полей с обработкой

---

### ❌ Не поддерживается (отсутствует в Grafana)

- `bdu_id` - российский идентификатор
- `operating_systems` - список ОС
- `hardware_platforms` - аппаратные платформы
- `date_discovered` - дата выявления
- `vulnerability_class` - класс уязвимости
- `error_type_russian` - тип ошибки на русском
- `weaknesses` (CWE) - не указывается
- `exploit_available` - не указывается явно
- `exploit_type` - не указывается

**Итого:** 9 полей отсутствуют

## 🔧 Настройка парсера

### Базовая конфигурация

```python
from services.parsers.grafana_parser import GrafanaSecurityParser

# Создать парсер
parser = GrafanaSecurityParser(
    cache_enabled=True,        # Включить кэширование
    rate_limit_delay=1.0       # Задержка между запросами (сек)
)

# Получить все advisory
advisories = parser.fetch_all_advisories()

# С фильтрами
critical_advisories = parser.fetch_all_advisories(severity='critical')
grafana_advisories = parser.fetch_all_advisories(product='grafana')
```

---

### Маппинг на БД

```python
from services.parsers.grafana_mapper import GrafanaDataMapper

mapper = GrafanaDataMapper()

# Преобразовать данные Grafana в формат БД
for advisory in advisories:
    db_data = mapper.map_to_db_format(advisory)
    
    # Сохранить в БД
    vulnerability_service.create_vulnerability(db_data)
```

## ⚠️ Важные замечания

### 1. HTML селекторы

**КРИТИЧЕСКИ ВАЖНО:** Селекторы в парсере являются **предположительными** и требуют уточнения после изучения реальной HTML структуры сайта Grafana.

**Что нужно сделать:**
1. Открыть https://grafana.com/security/security-advisories/
2. Изучить HTML структуру (DevTools → Elements)
3. Уточнить селекторы в `grafana_parser.py`:
   - Селектор таблицы advisory
   - Селекторы ячеек таблицы
   - Селекторы метаданных на детальной странице
   - Селекторы контента (Summary, Credits)

**Примеры мест для уточнения:**
```python
# В методе fetch_advisories_list()
table = soup.find('table')  # ← Уточнить селектор
rows = table.find_all('tr')[1:]

# В методе fetch_advisory_detail()
meta_items = soup.find_all('div', class_='meta-item')  # ← Уточнить
summary_heading = soup.find(['h2', 'h3'], text=re.compile(r'Summary'))  # ← Уточнить
```

---

### 2. Rate Limiting

**Уважайте сервер Grafana:**
- Задержка между запросами: минимум 1 секунда
- Используйте кэширование
- Не делайте слишком частые полные синхронизации

```python
# Хорошо
parser = GrafanaSecurityParser(rate_limit_delay=1.0)

# Плохо
parser = GrafanaSecurityParser(rate_limit_delay=0.1)  # Слишком быстро!
```

---

### 3. Обработка ошибок

Парсер может столкнуться с:
- Изменением структуры HTML
- Сетевыми ошибками
- Отсутствием некоторых полей

**Рекомендации:**
- Всегда проверяйте логи
- Используйте `--dry-run` перед полным импортом
- Регулярно тестируйте парсер
