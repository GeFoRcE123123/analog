## 🎯 Что заполняется из Grafana

### ✅ Полностью поддерживается (100%)

**Основные поля:**
- `cve_id` - CVE идентификатор
- `title` - название уязвимости
- `description` - полное описание

**БДУ поля:**
- `vendor` - "Grafana Labs"
- `product_name` - название продукта
- `cvss_score` - оценка CVSS
- `severity` - уровень опасности
- `metrics.cvss_v3` - детальные метрики CVSS
- `published_date` - дата публикации
- `remediation_method` - "Обновление ПО"
- `remediation_info` - информация об устранении
- `references` - ссылки на источники
- `vendor_comments` - благодарности

---

### ⚠️ Частично поддерживается

**БДУ поля:**
- `affected_versions` - из Fixed Versions (требует инверсии)
- `software_type` - определяется автоматически по product_name
- `remediation_date` - используется published_date
- `exploitation_method` - извлекается из Summary (если есть)
- `last_modified_date` - из Updated Date (если указана)

---

### ❌ Не поддерживается (отсутствует в Grafana)

**БДУ поля:**
- `bdu_id` - российский идентификатор
- `operating_systems` - список ОС
- `hardware_platforms` - аппаратные платформы
- `date_discovered` - дата выявления (используется published_date)
- `vulnerability_class` - класс уязвимости
- `error_type_russian` - тип ошибки на русском
- `weaknesses` (CWE) - не указывается в Grafana advisory
- `exploit_available` - не указывается явно
- `exploit_type` - не указывается
- `bdu_status` - статус по БДУ (не применимо)

vulnerability = {

    "weaknesses": None

---

### Сценарий 2: Grafana + NVD данные

```python
# Уязвимость есть и в Grafana, и в NVD
# Объединение данных

def merge_grafana_with_nvd(grafana_data, nvd_data):
    """
    Приоритет:
    1. Vendor-specific (Grafana) - для vendor, product, remediation
    2. NVD - для CWE, CPE, дополнительных ссылок
    """
    merged = {
        # Из Grafana (приоритет)
        "vendor": grafana_data["vendor"],
        "product_name": grafana_data["product_name"],
        "affected_versions": grafana_data["affected_versions"],
        "remediation_info": grafana_data["remediation_info"],
        
        # Из NVD (дополнение)
        "weaknesses": nvd_data.get("weaknesses"),
        "configurations": nvd_data.get("configurations"),
        
        # Объединение ссылок
        "references": grafana_data["references"] + nvd_data.get("references", []),
        
        # Метаданные
        "sources": ["grafana", "nvd"]
    }
    
    return merged
```

---

### Сценарий 3: Grafana + БДУ данные

```python
# Уязвимость есть во всех трех источниках
# Максимально полные данные

def merge_all_sources(grafana_data, nvd_data, bdu_data):
    """
    Приоритет полей:
    1. БДУ - для российских полей (bdu_id, русские описания)
    2. Grafana - для vendor-specific (remediation, versions)
    3. NVD - для стандартных полей (CWE, CPE)
    """
    merged = {
        # БДУ (приоритет для российских полей)
        "bdu_id": bdu_data.get("bdu_id"),
        "vulnerability_class": bdu_data.get("vulnerability_class"),
        "error_type_russian": bdu_data.get("error_type_russian"),
        
        # Grafana (приоритет для vendor-specific)
        "vendor": grafana_data["vendor"],
        "product_name": grafana_data["product_name"],
        "remediation_info": grafana_data["remediation_info"],
        
        # NVD (дополнение)
        "weaknesses": nvd_data.get("weaknesses"),
        "configurations": nvd_data.get("configurations"),
        
        # Объединение всех ссылок
        "references": (
            grafana_data["references"] +
            nvd_data.get("references", []) +
            bdu_data.get("references", [])
        ),
        
        # Метаданные
        "sources": ["bdu_fstec", "grafana", "nvd"]
    }
    
    return merged
```

## 🔍 Примеры несовпадений

### Пример 1: Разные названия

**БДУ:** "Уязвимость раскрытия конфиденциальной информации в Grafana"  
**Grafana:** "Exposure of Storage Secret in Pyroscope"  
**NVD:** "Grafana Pyroscope information disclosure vulnerability"

**Решение:** Использовать название из Grafana (vendor-specific), сохранить БДУ название в `title_russian`.

---

### Пример 2: Разные версии

**БДУ:** "Уязвимы версии до 1.15.2"  
**Grafana:** "Fixed in >=1.15.2 <1.16.0"  
**NVD:** "Versions 1.15.0 through 1.15.1"

**Решение:** Использовать Grafana формат (наиболее точный), конвертировать для БДУ формата.

---

### Пример 3: Отсутствие CWE

**БДУ:** CWE-200 (Information Exposure)  
**Grafana:** -  
**NVD:** CWE-200

**Решение:** Взять CWE из NVD или БДУ, если Grafana не указывает.
