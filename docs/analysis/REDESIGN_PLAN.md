# 🏗️ ПЛАН РЕДИЗАЙНА ПРОЕКТА

## 📋 ОБЩАЯ СТРАТЕГИЯ

Редизайн проекта для разделения на 4 VM с использованием переменной окружения `APP_ROLE`:
- **VM 230**: Database (PostgreSQL)
- **VM 231/10**: Frontend (UI-маршруты, статика, без БД)
- **VM 232/20**: Backend (API-маршруты, бизнес-логика, с БД)
- **VM 233/23**: Parsers (фоновые задачи, без Flask, с БД)

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### APP_ROLE значения:

- `frontend` - только UI-маршруты, без БД
- `backend` - только API-маршруты, с БД
- `parsers` - фоновые задачи, без Flask, с БД
- `full` - старое поведение (все в одном, для совместимости)

### Структура файлов после редизайна:

```
services/backend/
├── app.py              # Фабрика приложения (выбирает frontend/backend)
├── frontend_app.py     # UI-маршруты
├── backend_app.py      # API-маршруты
├── common.py           # Общие функции
└── ...
```
