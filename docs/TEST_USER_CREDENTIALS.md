# Тестовый пользователь системы

## Данные для входа

### Тестовый пользователь (user)
- **Email:** test@example.com
- **Пароль:** Test123!
- **Роль:** user (обычный пользователь)
- **Полное имя:** Тестовый пользователь

### Администратор (admin)
- **Email:** admin@example.com
- **Пароль:** Admin123!
- **Роль:** admin (администратор)
- **Полное имя:** Системный администратор

## Как войти

1. Перейдите на страницу: `http://10.0.88.20:5000/auth/login`
2. Введите email и пароль
3. Нажмите "Войти"

## Права доступа

### Тестовый пользователь (user)
- ✅ Просмотр уязвимостей
- ✅ Просмотр своих назначенных уязвимостей
- ❌ Управление операторами
- ❌ Запуск парсинга

### Администратор (admin)
- ✅ Все права тестового пользователя
- ✅ Управление операторами (`/operators`)
- ✅ Запуск парсинга уязвимостей (`/parsers`)
- ✅ Просмотр всех пользователей (`/admin/users`)

## Создание пользователя

Пользователь был создан скриптом `scripts/create_test_user.py`:

```bash
# Запуск на сервере базы данных (10.0.88.11)
cd /path/to/project
python3 scripts/create_test_user.py
```

## Проверка пользователей в БД

```sql
-- Просмотр всех пользователей
SELECT id, username, email, role, is_active, full_name FROM users ORDER BY id;
```

Результат:
```
 id | username |       email       | role  | is_active |        full_name
----+----------+-------------------+-------+-----------+-------------------------
  1 | admin    | admin@example.com | admin | t         | Системный администратор
  2 | testuser | test@example.com  | user  | t         | Тестовый пользователь
```

## Примечания

- Пароли хешируются с помощью bcrypt
- Пользователи активны по умолчанию
- Блокировка аккаунта после 5 неудачных попыток входа (на 15 минут)
- История входов сохраняется в таблице `login_attempts`
