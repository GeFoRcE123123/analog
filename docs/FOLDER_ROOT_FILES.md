## 📋 Обзор

Корневая директория проекта содержит основные конфигурационные файлы, точку входа приложения и вспомогательные скрипты для быстрого доступа.

## 📄 Основные файлы

### 1. `app.py`
**Назначение:** Главная точка входа Flask приложения (устаревшая)

**Статус:** ⚠️ Устаревший файл, используется для обратной совместимости

**Функционал:**

**Планы по доработке:**

- [ ] Удалить после полной миграции

---

### 2. `config.py`
**Назначение:** Конфигурация проекта

**Функционал:**
- Настройки подключения к БД
- Настройки сервисов (backend, frontend)
- Настройки парсеров
- Настройки NVD API
- Настройки ML платформы
- Настройки VM (IP адреса)

**Основные классы:**
- `DatabaseConfig` - конфигурация БД
- `Config` - основная конфигурация

**Ключевые настройки:**
- `DATABASE_CONFIG` - настройки PostgreSQL
- `BACKEND_HOST/PORT` - настройки backend сервера
- `FRONTEND_URL` - URL frontend
- `NVD_API_KEY` - ключ для NVD API
- `USE_LEGACY_SCHEMA` - использование legacy схемы БД
- `ML_PLATFORM_VM_IP` - IP ML платформы

**Планы по доработке:**
- [ ] Вынести конфигурацию в переменные окружения
- [ ] Добавить поддержку .env файлов
- [ ] Разделить на несколько конфигурационных файлов
- [ ] Добавить валидацию конфигурации
- [ ] Добавить примеры конфигураций
