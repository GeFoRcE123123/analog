# Оптимизация NVD синхронизации

## ✅ Настройки для максимальной скорости парсинга

### Полная синхронизация (Full Sync)
Используется для первоначальной загрузки всех уязвимостей из NVD:

- **Запросов в секунду**: 50 (максимум с API ключом)
- **Количество потоков**: 20 (увеличено для максимальной параллельности)
- **Назначение**: Быстрая полная синхронизация всего каталога NVD

### Инкрементальная синхронизация (Incremental Sync)
Используется для регулярных обновлений (только новые/измененные уязвимости):

- **Запросов в секунду**: 50 (максимум с API ключом)
- **Количество потоков**: 10 (оптимизировано для небольших объемов)
- **Назначение**: Эффективное получение изменений за последние N дней

---

## 📊 Конфигурация

Настройки находятся в `config.py`:

```python
# Полная синхронизация (максимальная скорость)
NVD_FULL_SYNC_REQUESTS_PER_SECOND = 50  # Запросов/сек
NVD_FULL_SYNC_MAX_WORKERS = 20          # Потоков

# Инкрементальная синхронизация (экономный режим)
NVD_INCREMENTAL_REQUESTS_PER_SECOND = 50  # Запросов/сек
NVD_INCREMENTAL_MAX_WORKERS = 10          # Потоков
```

---

## 🚀 Использование

### Полная синхронизация (один раз, затем по необходимости)

```python
from services.nvd_integration_service import NVDIntegrationService
from models.postgres_repositories import PostgresVulnerabilityRepository
from database.database_manager import DatabaseManager

db_manager = DatabaseManager()
vuln_repo = PostgresVulnerabilityRepository(db_manager.connection)
nvd_service = NVDIntegrationService(vuln_repo)

# Запуск полной синхронизации (использует 20 потоков, 50 req/sec)
stats = nvd_service.full_sync()
print(f"Синхронизировано: {stats['saved_count']} уязвимостей")
```

### Инкрементальная синхронизация (регулярно)

```python
# Синхронизация за последние 7 дней (использует 10 потоков, 50 req/sec)
stats = nvd_service.incremental_sync(days=7)

# Или за последний день (для ежедневных обновлений)
stats = nvd_service.incremental_sync(days=1)
```

## ⚡ Производительность

### Полная синхронизация:
- **Потоков**: 20 (максимальная параллельность)
- **Запросов/сек**: 50 (максимум API)
- **Скорость**: ~1000 записей/сек (теоретически)
- **Время**: Зависит от общего количества CVE в NVD

### Инкрементальная синхронизация:
- **Потоков**: 10 (достаточно для небольших объемов)
- **Запросов/сек**: 50 (максимум API)
- **Скорость**: Быстрая обработка изменений за последние дни
- **Время**: Обычно несколько минут для последних 7 дней

---

## 🔄 Рекомендуемая стратегия

1. **Первоначальная загрузка**: Запустить `full_sync()` один раз
   - Использует максимальные ресурсы (20 потоков, 50 req/sec)
   - Загрузит все существующие уязвимости

2. **Регулярные обновления**: Запускать `incremental_sync(days=1)` ежедневно
   - Использует оптимизированные ресурсы (10 потоков, 50 req/sec)
   - Получает только новые/измененные уязвимости

3. **Периодическая полная синхронизация**: Запускать `full_sync()` раз в неделю/месяц
   - Обеспечивает актуальность всех данных
   - Исправляет возможные пропуски
