## 📥 Как использовать импорт BDU

### Вариант 1: Через API (POST запрос)

```bash
# С авторизацией (нужен session cookie)
curl -X POST \
  -b "session=your_session_cookie" \
  -H "Content-Type: application/json" \
  http://10.0.88.20:5000/api/bdu/import
```

**Ответ:**
```json
{
  "success": true,
  "created": 150,
  "updated": 25,
  "errors": [],
  "total_rows": 175
}
```

### Вариант 2: Через веб-интерфейс

1. Открой: http://10.0.88.20:5000
2. Войди в систему (admin)
3. Открой консоль браузера (F12)
4. Выполни:
```javascript
fetch('/api/bdu/import', {
  method: 'POST',
  credentials: 'include'
}).then(r => r.json()).then(console.log)
```

## 📋 Формат Excel файла

Файл должен находиться по пути: `docs/парсеры ии бду.xlsx`

**Структура:**
- Первая строка: заголовок "Общая информация"
- Вторая строка: реальные заголовки колонок
- Третья строка и далее: данные

**Обязательные колонки:**
- `Идентификатор` - BDU ID (например, `BDU:2024-02893`)
- `Идентификаторы других систем описаний уязвимости` - CVE ID (например, `CVE-2023-0437`)
- `Наименование уязвимости` - краткое название
- `Описание уязвимости` - полное описание

**Опциональные колонки:**
- `Статус` - статус уязвимости в BDU
- `Вендор ПО` - вендоры
- `Название ПО` - названия ПО
- `Версия ПО` - версии
- `Наименование ОС и тип аппаратной платформы` - ОС/платформы
- `Дата выявления` - дата обнаружения
- `Уровень опасности уязвимости` - текстовое описание уровня
- `CVSS 2.0`, `CVSS 3.1`, `CVSS 4.0` - CVSS векторы
- `Возможные меры по устранению` - рекомендации
- `Статус уязвимости` - статус устранения
- `Информация об устранении` - детали устранения
- `Дата устранения` - дата фикса
- `Наличие эксплойта` - флаг эксплойта
- `Способ устранения` - метод фикса
- `Способ эксплуатации` - метод эксплуатации
- `Ссылки на источники` - URL ссылки
- `Описание ошибки CWE` - описание CWE
- `Тип ошибки CWE` - CWE ID

## 🔄 Логика импорта

1. **Чтение Excel:**
   - Пропускается первая строка (заголовок)
   - Вторая строка используется как заголовки колонок
   - Остальные строки - данные

2. **Обработка каждой строки:**
   - Извлечение CVE ID из колонки "Идентификаторы других систем..."
   - Поиск существующей уязвимости по CVE ID
   - Если найдена:
     - Дополнение описания блоком `[BDU/FSTEC] ...`
     - Обновление severity и cvss_score если выше
   - Если не найдена:
     - Создание новой уязвимости с полным описанием из Excel

3. **Формирование описания:**
   - Собирается расширенное описание из всех полей Excel
   - Включает: название, описание, вендоры, ПО, версии, ОС, даты, уровень опасности, CVSS, меры, статус, эксплойт, ссылки, CWE
