# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `schema/`

## 📋 Обзор

Папка `schema/` содержит официальную схему CVE JSON 5.x из репозитория CVEProject/cve-schema. Схема используется для валидации и парсинга CVE записей в формате JSON 5.x.

## 🎯 Основной функционал

Папка `schema/` обеспечивает:
- **Валидацию CVE записей** в формате JSON 5.x
- **JSON схемы** для CVE Record Format
- **Валидаторы** для проверки данных
- **Примеры** CVE записей
- **Импортируемые схемы** (CVSS, теги)

## 📂 Структура папки

```
schema/
└── cve_json5/
    ├── schemas/              # JSON схемы
    ├── examples/              # Примеры CVE записей
    ├── validators/            # Валидаторы
    ├── imports/               # Импортируемые схемы
    └── tags/                  # Теги для ссылок
```

### Validators (`validators/`)

#### 1. `cve_json5_validator.py`
**Назначение:** Обертка для валидации CVE JSON 5.x записей

**Функционал:**
- Валидация одной записи
- Валидация файла
- Валидация списка записей
- Возврат ошибок валидации

**Использование:**
```python
from schema.cve_json5.validators.cve_json5_validator import cve_json5_validator

# Валидация одной записи
is_valid, errors = cve_json5_validator.validate(cve_record)

# Валидация файла
is_valid, errors = cve_json5_validator.validate_file('cve_record.json')

# Валидация списка записей
results = cve_json5_validator.validate_batch(cve_records)
```
