# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `agents/`

## 📋 Обзор

Папка `agents/` содержит систему автономных агентов для автоматического мониторинга ошибок, исправления кода и деплоя на виртуальные машины. Агенты работают в автономном режиме и могут автоматически исправлять типичные ошибки.

## 🎯 Основной функционал

Система агентов обеспечивает:
- **Мониторинг ошибок** в реальном времени
- **Автоматическое исправление** типичных ошибок кода
- **Автоматический деплой** на 4 VM (frontend, backend, database, parsers)
- **Мониторинг здоровья** сервисов после деплоя
- **Автономный цикл** деплоя с повторными попытками

## 📄 Файлы и их функционал

### 1. `error_monitor.py`
**Назначение:** Анализ вывода терминала и определение типов ошибок

**Основные функции:**
- Парсинг ошибок из stdout/stderr
- Определение типа ошибки (AttributeError, ImportError, UndefinedColumn и т.д.)
- Извлечение контекста (файл, строка, детали)
- Генерация JSON с информацией об ошибках

**Поддерживаемые типы ошибок:**
- `AttributeError` - обращение к несуществующим атрибутам
- `ImportError` - отсутствующие модули
- `UndefinedColumn` - несуществующие колонки в БД
- `PermissionError` - проблемы с правами доступа
- `ConnectionError` - проблемы с подключением к БД
- `SyntaxError` - синтаксические ошибки

**Использование:**
```bash
python app.py 2>&1 | python agents/error_monitor.py
tail -f app.log | python agents/error_monitor.py
```

**Выходной формат:**
```json
{
  "error_type": "AttributeError",
  "file": "app.py",
  "line": 123,
  "details": ["NoneType", "id"],
  "suggested_fix": "Добавить проверку на None",
  "timestamp": "2025-01-20T20:00:00"
}
```

### 2. `code_fixer.py`
**Назначение:** Автоматическое исправление кода на основе обнаруженных ошибок

**Основные функции:**
- Чтение JSON с ошибками из stdin
- Применение исправлений в зависимости от типа ошибки
- Модификация файлов кода и конфигурации
- Логирование примененных исправлений

**Поддерживаемые исправления:**
- `UndefinedColumn` - комментирование несуществующих колонок в SQL запросах
- `AttributeError` - добавление проверок на None перед обращением к атрибутам
- `ImportError` - автоматическое добавление модулей в requirements.txt
- `PermissionError` - создание скрипта для исправления прав доступа
- `ConnectionError` - проверка и исправление строк подключения к БД

**Использование:**
```bash
python agents/error_monitor.py < errors.log | python agents/code_fixer.py
echo '{"error_type": "ImportError", "details": ["bcrypt"]}' | python agents/code_fixer.py
```

**Выходной формат:**
```json
{
  "total_errors": 2,
  "fixes_applied": 2,
  "fixes": [
    {
      "file": "requirements.txt",
      "error_type": "ImportError",
      "fix": "Added bcrypt>=4.0.0 to requirements.txt"
    }
  ]
}
```

### 3. `deploy_agent.py`
**Назначение:** Автоматический деплой и мониторинг сервисов на виртуальных машинах

**Основные функции:**
- Проверка доступности VM (ping)
- Проверка здоровья сервисов (HTTP, TCP порты)
- Деплой сервисов на конкретные VM
- Мониторинг состояния деплоя в реальном времени
- Автоматическое определение проблем и их исправление

**Конфигурация VM:**
```python
vms = {
    'frontend': {'ip': '10.0.88.10', 'port': 80, 'service': 'nginx'},
    'backend': {'ip': '10.0.88.20', 'port': 5000, 'service': 'flask'},
    'database': {'ip': '10.0.88.11', 'port': 5432, 'service': 'postgres'},
    'parsers': {'ip': '10.0.88.23', 'port': None, 'service': 'python'}
}
```

**Использование:**
```bash
# Деплой всех сервисов
python agents/deploy_agent.py --all

# Деплой конкретного сервиса
python agents/deploy_agent.py --service backend

# Мониторинг состояния
python agents/deploy_agent.py --monitor --interval 30
```

### 5. `autonomous_deploy.sh`
**Назначение:** Полный автономный цикл деплоя с мониторингом и автоматическим исправлением

**Основные функции:**
- Объединение всех агентов в один процесс
- Запуск деплоя с мониторингом ошибок
- Автоматическое исправление найденных ошибок
- Перезапуск деплоя после исправлений
- Проверка здоровья всех сервисов
- Повторные попытки до успешного деплоя (макс. 3 попытки)

**Использование:**
```bash
./agents/autonomous_deploy.sh
```

**Алгоритм работы:**
1. Запуск деплоя с перенаправлением вывода в error_monitor
2. Анализ ошибок и применение исправлений через code_fixer
3. Перезапуск деплоя после исправлений
4. Проверка здоровья сервисов через deploy_agent
5. Повтор до успешного деплоя или достижения лимита попыток

## 📝 Примечания

- Все агенты написаны на Python 3

- Агенты могут работать как автономно, так и в составе CI/CD пайплайна
- Для работы требуется настроенная сеть между VM (10.0.88.0/24)
