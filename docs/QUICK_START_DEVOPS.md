# 🚀 Быстрый старт DevOps-агента

## Запуск

```bash
./devops_agent.sh
```

## Что делает агент

1. ✅ Запускает все 4 VM (если не запущены)
2. ✅ Настраивает автозапуск через systemd
3. ✅ Тестирует все сервисы
4. ✅ Исправляет типичные проблемы
5. ✅ Создает отчет

## Результат

После выполнения вы получите:
- Все VM запущены и настроены
- Все сервисы работают
- Отчет в файле `devops_agent_report_*.txt`

## Проверка

```bash
# Проверка веб-интерфейса
curl http://10.0.88.10

# Проверка Backend API
curl http://10.0.88.20:5000/api/health

# Просмотр отчета
cat devops_agent_report_*.txt
```
