# Исправление проблемы парсинга (0 результатов)

## Проблема
Кнопка парсинга выдает 0 результатов. При запуске парсинга `parsing_id` возвращается как `null`.

## Найденные проблемы

### 1. Ошибка в `save_parsing_history`
**Ошибка:** `object of type 'int' has no len()`
**Причина:** `db_manager.execute_query()` возвращает результат в разных форматах:
- Может быть список кортежей: `[(id,)]`
- Может быть просто значение: `id`
- Может быть кортеж: `(id,)`

**Исправление:** Добавлена правильная обработка всех форматов результата.

### 2. Отсутствие `scan_date` в INSERT
**Проблема:** При создании записи не указывается `scan_date`, что может вызывать проблемы.

**Исправление:** Добавлен `NOW()` в INSERT запрос.

### 3. Неправильная обработка JSON
**Проблема:** `sources` может быть списком, но не сериализуется в JSON.

**Исправление:** Добавлена проверка типа и сериализация в JSON.
