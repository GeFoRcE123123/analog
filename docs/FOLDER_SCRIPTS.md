# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `scripts/`

## 📋 Обзор

Папка `scripts/` содержит все скрипты для развертывания, миграции, мониторинга и управления проектом. Скрипты разделены по категориям для удобства навигации.

## 🎯 Основной функционал

Папка `scripts/` обеспечивает:
- **Развертывание** сервисов на виртуальные машины
- **Миграции базы данных** и схемы
- **Мониторинг** состояния сервисов
- **Диагностику** и проверку соединений
- **Утилиты** для работы с данными
- **AI/ML** скрипты для анализа

## 📂 Структура папки

```
scripts/
├── ai/                    # AI/ML скрипты
├── diagnostics/           # Диагностические скрипты
├── frontend/              # Frontend утилиты
├── k8s_worker/            # Kubernetes worker скрипты
├── migration/             # Скрипты миграции БД
├── monitoring/             # Скрипты мониторинга
├── parsers/               # Скрипты запуска парсеров
├── utils/                 # Вспомогательные утилиты
└── [основные скрипты]     # Основные скрипты развертывания
```

## 📄 Основные скрипты развертывания

### 1. `deploy.sh`
**Назначение:** Основной скрипт развертывания всех сервисов

**Функционал:**
- Развертывание на все VM (frontend, backend, database, parsers)
- Проверка зависимостей
- Запуск Docker контейнеров
- Проверка здоровья сервисов

**Использование:**
```bash
./scripts/deploy.sh all          # Развернуть все
./scripts/deploy.sh backend      # Только backend
./scripts/deploy.sh frontend     # Только frontend
```

## 📝 Примечания

- Все скрипты должны быть исполняемыми (`chmod +x`)
- Скрипты используют bash для Linux/macOS
- Требуется доступ к VM по SSH для развертывания
- Некоторые скрипты требуют sudo прав
