# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `services/`

## 📋 Обзор

Папка `services/` содержит основной бизнес-логику приложения Vulnerability Manager. Здесь находятся все сервисы для работы с уязвимостями, парсеры, интеграции с внешними API, система аутентификации, аналитика и многое другое.

## 🎯 Основной функционал

Папка `services/` обеспечивает:
- **Бизнес-логику** работы с уязвимостями и операторами
- **Парсинг уязвимостей** из различных источников (NVD, RedHat, OSV, Debian и др.)
- **Интеграцию с внешними API** (NVD API, CVE.org, OSV API)
- **Аутентификацию и авторизацию** пользователей
- **Аналитику и отчетность** по уязвимостям
- **AI/ML интеграцию** для анализа уязвимостей
- **Экспорт данных** в различные форматы
- **Управление назначениями** уязвимостей операторам

## 📂 Структура папки

```
services/
├── backend/              # Backend Flask приложение
├── frontend/             # Frontend конфигурация (Nginx)
├── parsers/              # Современные парсеры (модульная архитектура)
├── legacy_parsers/       # Legacy парсеры (старая архитектура)
├── database/             # Управление базой данных
├── utils/                # Вспомогательные утилиты
└── [множество сервисов]  # Основные сервисы
```

## 📄 Основные сервисы

### 1. `vulnerability_service.py`
**Назначение:** Основной сервис для работы с уязвимостями

**Основные функции:**
- Получение уязвимостей с пагинацией и фильтрацией
- Поиск уязвимостей по различным критериям
- Создание, обновление и удаление уязвимостей
- Работа с тегами и AI-анализом
- Поддержка legacy и modern схем БД

**Ключевые методы:**
- `get_all_vulnerabilities()` - получить все уязвимости
- `get_paginated_vulnerabilities()` - получить с пагинацией
- `get_vulnerability_by_id()` - получить по ID
- `create_vulnerability()` - создать новую
- `update_vulnerability()` - обновить существующую
- `delete_vulnerability()` - удалить
