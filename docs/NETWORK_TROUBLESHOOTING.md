# Устранение сетевых проблем

## Проблема: "Network is unreachable" или "Connection refused"

### Причины:

1. **VM не запущена**
2. **Неправильный IP адрес**
3. **Сетевая изоляция / Firewall блокирует**
4. **Нет маршрута к сети 10.0.88.0/24**

---

## Проверка доступности

### 1. Проверить доступность VM

```bash
# Ping для проверки доступности
ping -c 3 10.0.88.11
ping -c 3 10.0.88.10
ping -c 3 10.0.88.20
ping -c 3 10.0.88.23
```

### 2. Проверить SSH доступ

```bash
# Проверить подключение
ssh -v user@10.0.88.11
```

### 3. Проверить сетевые настройки на вашей машине

```bash
# Проверить маршруты
netstat -rn | grep 10.0.88
# или
route -n | grep 10.0.88

# Проверить сетевые интерфейсы
ifconfig | grep -A 5 "inet"
# или
ip addr show
```

---

## Решения

### Если VM находятся в другой сети / VPN

1. **Подключиться к VPN**, если VM доступны только через него
2. **Настроить SSH туннель** или VPN туннель
3. **Использовать другой IP**, если VM доступны по другому адресу

### Если VM локальные (VMware/VirtualBox)

1. **Проверить настройки сети VM** - должна быть Bridge или NAT
2. **Убедиться, что VM запущены**
3. **Проверить IP адреса VM** - могут быть другие

### Если используете удаленные серверы

1. **Проверить Firewall правила** - порт 22 должен быть открыт
2. **Проверить Security Groups** (если облако)
3. **Проверить, что сервисы запущены на VM**

## Быстрая проверка всех VM

```bash
#!/bin/bash
for ip in 10.0.88.10 10.0.88.11 10.0.88.20 10.0.88.23; do
    echo "Проверка $ip..."
    if ping -c 1 -W 2 $ip >/dev/null 2>&1; then
        echo "✅ $ip доступен"
        if ssh -o ConnectTimeout=5 -o StrictHostKeyChecking=no user@$ip "echo OK" >/dev/null 2>&1; then
            echo "   ✅ SSH работает"
        else
            echo "   ❌ SSH не работает"
        fi
    else
        echo "❌ $ip недоступен"
    fi
done
```

## Альтернативный вариант: Изменить IP адреса

Если VM находятся по другим адресам, можно обновить скрипт:

В `deploy.sh` изменить:
```bash
FRONTEND_IP="<ваш_ip>"
BACKEND_IP="<ваш_ip>"
DATABASE_IP="<ваш_ip>"
PARSERS_IP="<ваш_ip>"
```

И в `config.py` обновить IP для Database.
