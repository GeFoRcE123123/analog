# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `ml_platform/`

## 📋 Обзор

Папка `ml_platform/` содержит распределенную платформу нейросетевых вычислений для обучения ML моделей и анализа безопасности. Платформа поддерживает как GPU, так и CPU вычисления и предоставляет REST API для удаленного управления.

## 🎯 Основной функционал

Папка `ml_platform/` обеспечивает:
- **Обучение ML моделей** на PyTorch
- **Автоматическое управление GPU** с graceful degradation на CPU
- **Сбор данных об уязвимостях** из различных источников
- **ML классификацию** уязвимостей
- **Расчет рисков** с ML коррекцией
- **Визуализацию** результатов обучения и безопасности
- **REST API** для удаленного управления
- **WebSocket** для real-time мониторинга

## 📂 Структура папки

```
ml_platform/
├── core/                    # Основные компоненты
├── api/                     # API компоненты
├── security/                # Модуль анализа безопасности
```
