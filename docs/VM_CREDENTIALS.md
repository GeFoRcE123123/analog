## ⚠️ ВАЖНО: Где выполнять команды

### ❌ НЕ выполняйте на вашем Mac!

Команды типа `sudo ufw disable` нужно выполнять **НА VM**, а не на вашем компьютере!

### ✅ Правильно:

1. **Откройте консоль VM** (через провайдера)
2. **Войдите в систему на VM**
3. **Выполните команды там**

---

## 🔧 Если забыли пароль sudo на VM

### Вариант 1: Попробовать стандартные пароли

```bash
# На VM попробуйте:
123
admin
password
(пустой пароль)
```

### Вариант 2: Войти как root

```bash
# На VM
su -
# Попробуйте пароли: 123, root, admin
```

### Вариант 3: Сбросить через консоль провайдера

1. Загрузитесь в recovery mode
2. Смонтируйте диск
3. Измените пароль
