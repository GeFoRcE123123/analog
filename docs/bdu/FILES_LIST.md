### 9. **scripts/migration/backfill_bdu_data.py** 🔄 BACKFILL СКРИПТ
```
Размер: ~15 KB
Назначение: Обратное заполнение БДУ данных из существующих записей
Технология: Python 3
```
**Содержание:**
- Класс `BDUDataExtractor` для извлечения данных
- 10+ regex паттернов для парсинга
- Методы извлечения для каждого типа данных:
  - `extract_bdu_id()`
  - `extract_vendor()`
  - `extract_product()`
  - `extract_exploit_info()`
  - `extract_date()`
- Функция `backfill_vulnerabilities()`
- CLI с аргументами:
  - `--dry-run` (тестовый прогон)
  - `--limit N` (ограничение)
  - `--verbose` (подробный вывод)
- Статистика и отчетность

**Использование:**
```bash
# Тестовый прогон
python scripts/migration/backfill_bdu_data.py --dry-run --limit 50 --verbose

# Полное выполнение
python scripts/migration/backfill_bdu_data.py
```
