# История изменений документации БДУ ФСТЭК

## Версия 1.1 - 22 января 2026

### 🔄 Реорганизация структуры

**Что изменилось:**
- Вся документация БДУ перемещена в отдельную папку `docs/bdu/`
- Файлы переименованы для краткости (без префикса BDU_)
- Обновлены все внутренние ссылки

**Старая структура:**
```
docs/
├── BDU_INDEX.md
├── BDU_QUICK_SUMMARY.md
├── BDU_ACTION_PLAN.md
├── BDU_STRUCTURE_ANALYSIS_2026.md
├── BDU_COMPARISON_DIAGRAM.md
└── BDU_FILES_CREATED.md
```

**Новая структура:**
```
docs/
├── BDU_README.md (ссылка на папку bdu/)
└── bdu/
    ├── README.md (главная страница)
    ├── QUICK_SUMMARY.md
    ├── ACTION_PLAN.md
    ├── STRUCTURE_ANALYSIS.md
    ├── COMPARISON_DIAGRAM.md
    ├── FILES_LIST.md
    └── CHANGELOG.md (этот файл)
```

### 📝 Переименования файлов

| Старое имя | Новое имя | Причина |
|------------|-----------|---------|
| `BDU_INDEX.md` | `README.md` | Стандартное имя для главной страницы |
| `BDU_QUICK_SUMMARY.md` | `QUICK_SUMMARY.md` | Убран префикс (уже в папке bdu/) |
| `BDU_ACTION_PLAN.md` | `ACTION_PLAN.md` | Убран префикс |
| `BDU_STRUCTURE_ANALYSIS_2026.md` | `STRUCTURE_ANALYSIS.md` | Убран префикс и год |
| `BDU_COMPARISON_DIAGRAM.md` | `COMPARISON_DIAGRAM.md` | Убран префикс |
| `BDU_FILES_CREATED.md` | `FILES_LIST.md` | Убран префикс, более понятное имя |

### ✅ Преимущества новой структуры

1. **Организация** - вся документация БДУ в одном месте
2. **Краткость** - имена файлов короче и понятнее
3. **Масштабируемость** - легко добавлять новые документы
4. **Навигация** - README.md как точка входа
5. **Совместимость** - файл BDU_README.md в корне docs/ для обратной совместимости

### 🔗 Обновленные ссылки

Все внутренние ссылки обновлены:
- ✅ Относительные пути внутри папки bdu/
- ✅ Ссылки на скрипты миграции (../../scripts/migration/)
- ✅ Перекрестные ссылки между документами

## Как использовать

### Если вы новый пользователь:
1. Начните с `README.md` в этой папке
2. Прочитайте `QUICK_SUMMARY.md`
3. Изучите `ACTION_PLAN.md`

### Если вы использовали старые ссылки:
- Замените `docs/BDU_INDEX.md` на `docs/bdu/README.md`
- Замените `docs/BDU_QUICK_SUMMARY.md` на `docs/bdu/QUICK_SUMMARY.md`
- И так далее (см. таблицу переименований выше)

### Обратная совместимость:
- Файл `docs/BDU_README.md` содержит ссылки на новое расположение
- Все старые файлы удалены, используйте новые пути
