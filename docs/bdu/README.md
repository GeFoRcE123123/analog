## 🎓 Обучающие материалы

### Что такое БДУ ФСТЭК?

**Банк данных угроз безопасности информации (БДУ ФСТЭК)** - это российская национальная база данных уязвимостей, поддерживаемая Федеральной службой по техническому и экспортному контролю.

**Официальный сайт:** https://bdu.fstec.ru

**Особенности:**
- Паспорт уязвимости на русском языке
- Фокус на российские продукты
- Статус подтверждения производителем
- Информация об устранении
- Поддержка CVSS 2.0, 3.x, 4.0

### Зачем нужна интеграция?

1. **Законодательство РФ** - требования регуляторов
2. **Полнота данных** - БДУ содержит уязвимости, отсутствующие в NVD
3. **Актуальность** - информация на русском языке
4. **Приоритизация** - статус подтверждения и информация об устранении

## ❓ Часто задаваемые вопросы (FAQ)

### Q: Сколько времени займет миграция БД?
**A:** ~1-2 часа на продакшн БД среднего размера (10-50K записей). Тестируйте сначала на копии!

### Q: Нужно ли останавливать систему на время миграции?
**A:** Рекомендуется остановить фоновые процессы парсинга, но основная система может работать (миграция выполняется в транзакции).

### Q: Что если миграция пойдет не так?
**A:** Есть полный rollback скрипт + обязательный бэкап перед миграцией. Восстановление за 5-10 минут.

### Q: Можно ли внедрять поэтапно?
**A:** Да! Можно сначала выполнить миграцию БД, затем постепенно обновлять Backend и Frontend.

### Q: Как проверить что всё работает?
**A:** Запустить `check_bdu_stats.sql` для проверки заполненности данных + ручное тестирование UI.

### Q: Производительность не упадет?
**A:** Наоборот! Индексированные поля дают 50-100x ускорение по сравнению с LIKE запросами.

### Q: Нужно ли обучение пользователей?
**A:** Минимальное. UI изменения интуитивны. Достаточно краткой демонстрации новых фильтров.
