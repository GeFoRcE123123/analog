## ⚠️ Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Миграция БД упадет | Низкая | Критичное | Тестовая БД + бэкап |
| Backfill не извлечет данные | Средняя | Среднее | Ручная проверка + улучшение regex |
| Производительность упадет | Низкая | Высокое | Нагрузочные тесты + индексы |
| Баги в UI | Средняя | Низкое | Тщательное тестирование |
| Команда не успеет | Низкая | Среднее | Резерв времени 20% |
