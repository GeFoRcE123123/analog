# Анализ методов Blue Team в системе управления уязвимостями

## Обзор

В процессе разработки системы управления уязвимостями были применены различные методы Blue Team (защитной команды информационной безопасности) для обеспечения безопасности системы и защиты данных.

---

## 1. 🔐 Аутентификация и авторизация (Authentication & Authorization)

### Реализованные методы:

#### 1.1 Хеширование паролей
- **Метод**: bcrypt с 12 раундами
- **Файл**: `services/auth_service.py`
- **Реализация**:
  ```python
  HASH_ROUNDS = 12  # bcrypt cost
  def hash_password(self, password: str) -> str:
      return bcrypt.hashpw(password.encode('utf-8'), 
                          bcrypt.gensalt(rounds=self.HASH_ROUNDS))
  ```
- **Blue Team практика**: Защита от утечек паролей через одностороннее хеширование

#### 1.2 Контроль доступа на основе ролей (RBAC)
- **Роли**: `admin`, `user`
- **Файл**: `utils/decorators.py`
- **Реализация**:
  ```python
  @login_required
  @admin_required
  def parsers_page():
      # Только администраторы могут управлять парсерами
  ```
- **Blue Team практика**: Принцип наименьших привилегий (Least Privilege)

#### 1.3 Блокировка учетных записей
- **Метод**: Автоматическая блокировка после неудачных попыток
- **Параметры**:
  - `MAX_FAILED_ATTEMPTS = 5`
  - `LOCKOUT_MINUTES = 15`
- **Blue Team практика**: Защита от брутфорс-атак
