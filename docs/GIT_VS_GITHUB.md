# 🔀 РАЗНИЦА МЕЖДУ GIT И GITHUB

## 📋 Краткое объяснение

**Git** = Инструмент (программа на вашем компьютере)  
**GitHub** = Сервис (веб-сайт в интернете)

---

## 🔧 GIT - Система контроля версий

### Что это:
- **Программа**, которая устанавливается на ваш компьютер/сервер
- **Локальная система** управления версиями кода
- Работает **без интернета** (локально)
- **Бесплатная** и открытая

### Что делает Git:
- ✅ Отслеживает изменения в файлах
- ✅ Сохраняет историю изменений
- ✅ Позволяет откатываться к предыдущим версиям
- ✅ Управляет ветками (branches)
- ✅ Объединяет изменения от разных разработчиков

### Где используется:
- На вашем компьютере
- На серверах (VM)
- В любой папке проекта

### Примеры команд Git:
```bash
git init          # Создать новый репозиторий
git add .         # Добавить файлы
git commit -m "..." # Сохранить изменения
git status        # Проверить статус
git log           # Посмотреть историю
```

---

## 🌐 GITHUB - Хостинг репозиториев

### Что это:
- **Веб-сервис** (сайт github.com)
- **Хранилище** для ваших Git репозиториев в интернете
- **Требует интернет** для работы
- **Бесплатный** для публичных проектов, платный для приватных

### Что делает GitHub:
- ✅ Хранит ваши репозитории в облаке
- ✅ Позволяет работать в команде
- ✅ Предоставляет веб-интерфейс
- ✅ CI/CD интеграции
- ✅ Issue tracking (отслеживание задач)
- ✅ Pull Requests (запросы на изменения)

### Где используется:
- В интернете (github.com)
- Доступен с любого компьютера
- Для совместной работы

### Примеры использования GitHub:
```bash
git clone https://github.com/user/repo.git  # Скачать репозиторий
git push origin main                        # Отправить изменения на GitHub
git pull                                    # Получить изменения с GitHub
```

## 🎯 Что вам нужно?

### Если нужен только Git (локальная работа):
```bash
# Git уже установлен на VM 10.0.88.41
git --version  # Проверить версию

# Можно работать локально:
git init
git add .
git commit -m "Изменения"
```

### Если нужен GitHub (работа в команде/облако):
1. Создать аккаунт на github.com
2. Создать репозиторий на GitHub
3. Подключить локальный Git к GitHub:
```bash
git remote add origin https://github.com/user/repo.git
git push -u origin main
```

## 💡 Аналогия

**Git** = Microsoft Word (программа на компьютере)  
**GitHub** = Google Docs (онлайн сервис)

- Word работает локально, сохраняет файлы на диск
- Google Docs работает в интернете, сохраняет в облаке
- Можно использовать Word без Google Docs
