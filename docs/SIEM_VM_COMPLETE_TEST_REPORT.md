## 🔧 Что нужно исправить

### Приоритет 1: Запустить Grafana

```bash
# На VM через SSH
ssh test@10.0.88.41

# Запустить Grafana
cd ~/monitoring/monitoring-stack
cd grafana && docker compose up -d
# или если нет отдельной директории:
# docker compose up -d grafana
```

### Приоритет 2: Исправить Promtail ошибки

```bash
# На VM
# Проверить доступ к Docker socket
sudo chmod 666 /var/run/docker.sock
# или добавить пользователя в группу docker
sudo usermod -aG docker test
```

### Приоритет 3: Проверить файрвол сети

Возможно, файрвол на уровне сети блокирует порты, но HTTP работает через другой механизм.
