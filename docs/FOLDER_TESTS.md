# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `tests/`

## 📋 Обзор

Папка `tests/` содержит все тесты для проверки работы системы. Тесты разделены по типам: unit-тесты, integration-тесты, тесты парсеров и валидация данных.

## 🎯 Основной функционал

Папка `tests/` обеспечивает:
- **Unit-тесты** для отдельных компонентов
- **Integration-тесты** для проверки взаимодействия
- **Тесты парсеров** для проверки парсинга данных
- **Валидацию данных** для проверки корректности
- **Автоматическое исправление** ошибок в тестах

## 📝 Примечания

- Тесты используют pytest как фреймворк
- Некоторые тесты требуют доступа к внешним API
- Используются моки для изоляции тестов
- Тесты с маркером `@pytest.mark.slow` могут выполняться долго
