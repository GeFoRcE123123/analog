# 📁 ДОКУМЕНТАЦИЯ ПАПКИ `templates/`

## 📋 Обзор

Папка `templates/` содержит HTML шаблоны для веб-интерфейса Vulnerability Manager. Шаблоны используют Jinja2 для рендеринга и наследуются от базового шаблона `base.html`.

## 🎯 Основной функционал

Папка `templates/` обеспечивает:
- **Веб-интерфейс** для работы с уязвимостями
- **Административный интерфейс** для управления системой
- **AI дашборды** для визуализации и анализа
- **Аутентификацию** пользователей
- **Отображение данных** в удобном формате

## 📂 Структура папки

```
templates/
├── admin/              # Административные страницы
├── ai/                 # AI дашборды
├── auth/               # Страницы аутентификации
└── [основные шаблоны]  # Основные страницы
```
