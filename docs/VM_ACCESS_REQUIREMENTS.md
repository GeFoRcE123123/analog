# 🔐 Требования для доступа к VM 10.0.88.25

## 📋 Необходимые данные

Для подключения к VM 10.0.88.25 (k8s-worker) нужны:

### 1. **SSH доступ**
- **IP адрес:** 10.0.88.25
- **Тип:** k8s-worker (Kubernetes worker node)
- **Пользователь:** `k8s-worker` (или другой, нужно уточнить)
- **Пароль:** `123` (или другой)
- **Порт SSH:** 22 (по умолчанию)

### 2. **Проверка доступа**

Выполните команду для проверки:
```bash
ssh k8s-worker@10.0.88.25
# или
sshpass -p '123' ssh k8s-worker@10.0.88.25 "whoami && hostname"
```

### 3. **Альтернативные методы**

Если SSH с паролем не работает:
- **SSH ключи:** Настройте ключевой доступ
- **kubectl:** Если это Kubernetes node, используйте kubectl
- **VPN/туннель:** Если требуется VPN для доступа

---

## 🔧 Что нужно для подключения

1. **Учетные данные:**
   - Имя пользователя (предположительно `k8s-worker`)
   - Пароль (предположительно `123` или другой)
   - Или SSH ключ

2. **Права доступа:**
   - Доступ к файловой системе
   - Возможность запуска Docker/Kubernetes команд
   - Права sudo (если требуется)

3. **Сетевой доступ:**
   - Доступность порта 22 (SSH)
   - Доступность портов для ИИ-системы (например, 8000, 8080)

---

## ✅ Рекомендуемые действия

1. Проверьте SSH доступ вручную
2. Настройте SSH ключи для безопасного доступа
3. Убедитесь, что пользователь имеет необходимые права
4. Проверьте доступность портов для ИИ-системы
