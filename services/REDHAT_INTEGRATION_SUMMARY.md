## Использование

### Через веб-интерфейс

1. Откройте `/parsers` страницу
2. Найдите секцию "Red Hat Парсер"
3. Выберите режим работы
4. Настройте параметры
5. Нажмите "Импортировать Red Hat CVE"

### Через командную строку

```bash
# Импорт из существующих файлов (лимит 1000)
python3 services/redhat_db_importer.py --data-dir cve_data/full --limit 1000

# Импорт из CSV
python3 services/redhat_db_importer.py --csv cve_data/full/redhat_all_cve.csv --limit 500

# Полный импорт (без ограничений)
python3 services/redhat_db_importer.py --data-dir cve_data/full
```

### Через API

```bash
# Синхронный импорт (для небольших объемов)
curl -X POST http://localhost:5000/api/redhat/import-sync \
  -H "Content-Type: application/json" \
  -H "Cookie: session=..." \
  -d '{
    "mode": "import",
    "import_limit": 100,
    "skip_existing": true
  }'
```
