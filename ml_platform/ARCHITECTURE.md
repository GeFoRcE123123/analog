# Архитектура платформы

## Обзор

Платформа реализует распределенную систему для обучения нейросетевых моделей согласно UML-диаграмме. Архитектура построена на принципах модульности, расширяемости и отказоустойчивости.

## Компоненты системы

### Core (Ядро платформы)

#### ConfigManager
- Управление конфигурацией из YAML/JSON файлов
- Поддержка переменных окружения
- Профили конфигурации для разных сценариев

#### Logger
- Централизованное логирование
- Интеграция с systemd journal
- Файловое логирование
- Уровни логирования (DEBUG, INFO, WARNING, ERROR)

#### GPUManager
- Автоматическое определение доступности CUDA
- Проверка драйверов NVIDIA
- Управление памятью GPU
- Graceful degradation на CPU
- Очистка кэша GPU

#### DataLoader
- Загрузка данных из различных форматов (CSV, Parquet, HDF5, Pickle)
- Валидация целостности данных
- Обработка пропущенных значений
- Нормализация данных
- Разделение на train/val/test
- Создание PyTorch DataLoader'ов

#### ModelValidator
- Валидация архитектуры модели
- Оценка модели на данных
- Вычисление метрик (accuracy, F1, precision, recall)
- Анализ причин низкой точности
- Проверка пороговых значений

#### Visualization
- Построение кривых обучения
- Визуализация матрицы ошибок
- Сравнение метрик
- Создание отчетов

#### ModelTrainer
- Основной класс обучения моделей
- Реализация полного алгоритма согласно UML
- Управление циклом обучения
- Early stopping
- Сохранение лучших весов
- Callback для прогресса

### API (Веб-интерфейс)

#### FastAPI Server
- REST API для управления обучением
- Endpoints для запуска, статуса, списка задач
- Health check и GPU status
- Prometheus метрики

#### WebSocket Manager
- Real-time отслеживание прогресса
- Broadcast обновлений всем подключенным клиентам
- Управление соединениями

### Models (Примеры моделей)

- SimpleClassifier - простой классификатор
- MLPRegressor - регрессионная модель
- CNNClassifier - CNN для изображений
- LSTMClassifier - LSTM для последовательностей

### Utils (Утилиты)

#### Prometheus Metrics
- Метрики обучения (started, completed, duration)
- Метрики моделей (accuracy, loss)
- Метрики GPU (memory usage, availability)
- Счетчики эпох

## Поток данных

```

    ↓
ModelTrainer
    ↓

    ↓
GPUManager → Определение устройства
    ↓
ModelTrainer → Подготовка модели
    ↓
Цикл обучения:
    - train_epoch()
    - validate_epoch()
    - Early stopping check
    ↓

    ↓
Visualization → Создание графиков
    ↓
Сохранение модели и результатов
```

## Алгоритм обучения (UML)

1. **Валидация скрипта** - проверка синтаксиса
2. **Инициализация модели** - создание или загрузка
3. **Загрузка весов** - предобученные или случайные
4. **Определение устройства** - GPU или CPU
5. **Загрузка данных** - из файла с валидацией
6. **Подготовка данных** - разделение, нормализация
7. **Цикл обучения**:
   - Прямой проход
   - Вычисление потерь
   - Обратное распространение
   - Обновление весов
   - Валидация
   - Early stopping
8. **Оценка модели** - тестирование
9. **Сохранение** - модель и визуализации

## Обработка ошибок

- **Валидация на каждом этапе** - проверка входных данных
- **Graceful degradation** - переход на CPU при проблемах с GPU
- **Численная стабильность** - обнаружение NaN/Inf
- **Восстановление** - автоматические повторы
- **Подробные логи** - детальная информация об ошибках

## Масштабируемость

- Модульная архитектура - легко добавлять новые компоненты
- Конфигурируемость - настройка через YAML/JSON
- API для удаленного доступа
- WebSocket для real-time мониторинга
- Prometheus для метрик

## Безопасность

- Валидация всех входных данных
- Обработка исключений
- Логирование для аудита
- Изоляция процессов обучения

## Расширяемость

- Легко добавлять новые типы моделей
- Поддержка новых форматов данных
- Кастомные метрики
- Плагины для визуализации
