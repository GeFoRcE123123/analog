### 5. Связи с Database (10.0.88.11)

#### 5.1 Текущая схема

**Таблица `turn`:**
- Содержит основную информацию об уязвимостях
- Готова к добавлению ИИ-полей

**Нужно добавить:**
```sql
-- Если поля еще не добавлены
ALTER TABLE turn ADD COLUMN IF NOT EXISTS is_ai_related BOOLEAN DEFAULT FALSE;
ALTER TABLE turn ADD COLUMN IF NOT EXISTS ai_confidence FLOAT DEFAULT 0.0;

-- Новая таблица для меток обучения
CREATE TABLE IF NOT EXISTS ai_training_labels (
    id SERIAL PRIMARY KEY,
    vulnerability_id INTEGER REFERENCES turn(id),
    label BOOLEAN,
    labeled_by INTEGER REFERENCES users(id),
    labeled_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Таблица для метрик моделей
CREATE TABLE IF NOT EXISTS ai_model_metrics (
    id SERIAL PRIMARY KEY,
    model_name VARCHAR(100),
    model_version VARCHAR(50),
    accuracy FLOAT,
    precision FLOAT,
    recall FLOAT,
    f1_score FLOAT,
    trained_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
