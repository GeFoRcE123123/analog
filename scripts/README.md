# 📜 СКРИПТЫ ПРОЕКТА

Эта папка содержит все скрипты для развертывания, миграции и управления проектом.

## 📋 Основные скрипты

### Развертывание
- `deploy.sh` - Основной скрипт развертывания
- `deploy_legacy_parsers.sh` - Развертывание legacy парсеров
- `deploy_ai_system.sh` - Развертывание AI системы

### Миграция
- `apply_migration.sh` - Применение миграций БД
- `apply_migration_direct.sh` - Прямое применение миграций
- `QUICK_MIGRATION_COMMANDS.sh` - Быстрые команды миграции

### Мониторинг
- `check_services.sh` - Проверка статуса сервисов
- `check_sync_status.sh` - Проверка статуса синхронизации

## 🚀 Использование

Все скрипты должны быть исполняемыми:
```bash
chmod +x scripts/*.sh
```

Запуск:
```bash
./scripts/deploy.sh
```
