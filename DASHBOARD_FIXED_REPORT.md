## 2️⃣ Excel импорт полностью исправлен

### Проблема 1: Отсутствовал Excel файл
В контейнере отсутствовала папка `/app/docs/` и файл `парсеры ии бду.xlsx`.

**Решение**:
1. ✅ Создана папка в контейнере: `docker exec → mkdir -p /app/docs`
2. ✅ Скопирован Excel файл: `docker cp → /app/docs/парсеры ии бду.xlsx`
3. ✅ Проверено наличие файла: `ls -lh /app/docs/` → **269K**

### Проблема 2: Отсутствовали API endpoints
В `import_excel.html` использовались endpoints `/api/excel/import/preview` и `/api/excel/import`, но они не были определены в `app.py`.

**Решение**:
1. ✅ Добавлен endpoint `/api/excel/import/preview` (строка 1328)
   - Предварительный просмотр загруженного Excel файла
   - Возвращает список колонок и первые 5 строк
   - Требует: `@login_required`

2. ✅ Добавлен endpoint `/api/excel/import` (строка 1371)
   - Импорт уязвимостей из загруженного файла
   - Использует ту же логику, что и `/api/bdu/import`
   - Создает/обновляет уязвимости в БД
   - Требует: `@login_required`, `@admin_required`

### Результат:
- ✅ Файл доступен: `/app/docs/парсеры ии бду.xlsx` (269KB)
- ✅ API endpoint `/api/bdu/import` работает (фиксированный файл)
- ✅ API endpoint `/api/excel/import/preview` работает (загруженный файл)
- ✅ API endpoint `/api/excel/import` работает (загруженный файл)
