# Стратегия синхронизации NVD

## 🎯 Оптимизированная конфигурация

### Полная синхронизация (Full Sync)
**Используется для**: Первоначальной загрузки всех уязвимостей из NVD

**Настройки**:
- **Запросов в секунду**: 50 (максимум с API ключом)
- **Количество потоков**: 20 (максимальная параллельность)
- **Скорость**: ~1000+ записей/сек (теоретически)

**Когда использовать**:
- Первый запуск системы
- Периодическая полная синхронизация (раз в неделю/месяц)
- После длительного простоя

### Инкрементальная синхронизация (Incremental Sync)
**Используется для**: Регулярных обновлений (только новые/измененные)

**Настройки**:
- **Запросов в секунду**: 50 (максимум с API ключом)
- **Количество потоков**: 10 (оптимизировано для небольших объемов)
- **Эффективность**: Быстрая обработка изменений

**Когда использовать**:
- Ежедневные обновления
- Регулярная синхронизация (каждый час/день)
- Получение только новых уязвимостей

---

## 📋 Рекомендуемая стратегия использования

### Шаг 1: Первоначальная полная синхронизация
```python
from services.nvd_integration_service import NVDIntegrationService
from models.postgres_repositories import PostgresVulnerabilityRepository
from database.database_manager import DatabaseManager

db_manager = DatabaseManager()
vuln_repo = PostgresVulnerabilityRepository(db_manager.connection)
nvd_service = NVDIntegrationService(vuln_repo)

# Запуск полной синхронизации (использует 20 потоков, 50 req/sec)
print("Запуск полной синхронизации...")
stats = nvd_service.full_sync()
print(f"✅ Синхронизировано: {stats['saved_count']} уязвимостей")
```

### Шаг 2: Регулярные инкрементальные обновления
```python
# Ежедневная синхронизация (использует 10 потоков, 50 req/sec)
stats = nvd_service.incremental_sync(days=1)
print(f"✅ Обновлено: {stats['saved_count']} новых уязвимостей")
```

### Шаг 3: Автоматизация (через планировщик)
```python
from services.nvd_scheduler import NVDScheduler

scheduler = NVDScheduler(nvd_service)
scheduler.start()

# Планировщик автоматически запускает incremental_sync каждый день
```

## ⚡ Производительность

### Сравнение:

| Параметр | Полная синхронизация | Инкрементальная синхронизация |
|----------|---------------------|-------------------------------|
| Потоков | 20 | 10 |
| Запросов/сек | 50 | 50 |
| Использование | Первый запуск | Регулярные обновления |
| Время | Зависит от объема | Несколько минут |
