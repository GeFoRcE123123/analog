2. Изменения в app.py
   Добавлены функции для обработки XML/JSON:
   parse_xml_vulnerability(vuln_elem, format_type) - парсинг уязвимостей из XML в различных форматах (OWASP, custom, NVD)
   parse_json_vulnerability(item) - парсинг уязвимостей из JSON объектов
   save_vulnerabilities_to_db(vulnerabilities, skip_duplicates, auto_generate_cve) - сохранение уязвимостей в базу данных с поддержкой настроек
   Добавлены API маршруты:
   /api/import/unified - универсальный эндпоинт для импорта XML/JSON файлов
   Поддерживает переключение формата через параметр format
   Имеет настройки пропуска дубликатов и автогенерации CVE
   Возвращает подробную статистику по импорту (сохранено/пропущено)
   /api/export/json - эндпоинт для экспорта данных в JSON формате
   Поддерживает параметры фильтрации: limit, status, min_cvss
   Генерирует файл для скачивания с метаданными
   /api/export/xml - эндпоинт для экспорта данных в XML формате
   Поддерживает те же параметры фильтрации
   Формирует XML в OWASP-совместимом формате для скачивания
   Удалены конфликтующие элементы:
   Удалены импорты и регистрация Blueprint для import_export_routes:
