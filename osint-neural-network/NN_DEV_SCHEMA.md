# OSINT Neural Network — Dev Schema (for Implementation Agent)

Цель: выполнить полную реализацию OSINT‑нейросети, довести проект до продакшен‑готовности и интегрировать в веб‑интерфейс.

## Контекст (текущее состояние)
- Основной код находится в `osint-neural-network/`.
- Реализованы: генерация синтетики, LoRA‑обучение, инференс, заглушки оценки, базовые интеграции (Shodan/Censys/DNS/GitHub/Nmap), FastAPI API.
- Отсутствуют: реальные данные, полноценная оценка, тесты, контейнеризация, продакшен‑инструменты, интеграция в веб‑сайт.

## Целевой результат
- Обучаемая модель с воспроизводимым пайплайном.
- Реальный датасет (или гибридный) + контроль качества.
- Полная оценка качества и этики.
- Интеграция в веб‑сайт (UI + backend route).
- Документация и инструкции запуска.
